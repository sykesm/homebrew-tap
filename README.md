# sykesm/tap

Homebrew packages for [sykesm](https://github.com/sykesm)'s tools.

```sh
brew install sykesm/tap/<name>
```

| Package | Description |
|---|---|
| [gogrc](https://github.com/sykesm/gogrc) | Colorize command output using grc's configuration |

Casks in `Casks/` are updated automatically when a project publishes a
release.
